## 화면 (기획 문서의 "메뉴바 드롭다운이 메인"은 폐기)
- **메인은 우측 상단에 떠 있는 작은 창**: 테두리 없는 `NSPanel` + SwiftUI. `level = .floating`, `.nonactivatingPanel`, `.canJoinAllSpaces`/`.fullScreenAuxiliary`, `hidesOnDeactivate = false`
- **평소 상태**: 기존 단색 디자인의 *배경만* 반투명(글자는 선명), 클릭은 뒤로 통과(`ignoresMouseEvents = true`). 투명도는 설정 슬라이더, 흐림(material/Liquid Glass)은 토글
- **활성 상태**: 메뉴바 아이콘 왼쪽 클릭 → 색이 차오르며 불투명, 조작 가능
  - 평소로 복귀: 아이콘 다시 클릭 / 창 밖 클릭(`NSEvent.addGlobalMonitorForEvents`) / 10초 무조작 (입력 중 제외)
  - 단축키(예: ⌥⌘K)로도 전환. "마우스 올리면 활성화"는 설정 옵션 (0.25초 머무름, 0.5초 유예)
- **메뉴바 아이콘**: `MenuBarExtra`가 아니라 `NSStatusItem` 직접 사용. 오른쪽 클릭 = 메뉴(2시간 깨어 있기, 창 숨기기, 설정, 종료). 아이콘 모양으로 상태 표시(꺼짐 / 깨어 있음 / 뚜껑 모드)
- 창 안: 깨어 있기 상태·남은 시간, 언제까지, 뚜껑 모드, "지금 닫으면 유지됨/잠듦", 에이전트 상태, 오늘 할 일. 접으면 한 줄("깨어 있는 중 · 1:42 · 할 일 3")

## 깨어 있기 구조 (확정)
- 세션 하나 + 옵션 두 개: **언제까지**(계속/1·2시간/직접/에이전트가 끝날 때까지), **뚜껑 닫아도 유지**(세션 안에서만)
- 세션이 끝나면 둘 다 꺼짐. 안전장치(발열·배터리)는 뚜껑 모드만 풀고 세션은 유지
- 깨어 있기 = `IOPMAssertion`, 뚜껑 모드 = `pmset -a disablesleep 1` (sudoers에 정확한 명령 3개만, `visudo -c` 검사)
- 자세한 주의사항은 `docs/기획.md`의 "주의해야 할 것"

## 코드 규칙
- UI와 무관한 로직(세션, 전원 판단, 안전장치, 할 일 저장소 프로토콜)은 `LanternKit`에. AppKit 의존은 앱 타깃에만
- SwiftData 모델은 나중에 CloudKit을 켤 수 있게: 모든 속성에 기본값 또는 옵셔널, `@Attribute(.unique)` 금지, 관계는 옵셔널
- 세션 상태·기록은 `Codable`
- 할 일 저장소는 프로토콜 뒤에
