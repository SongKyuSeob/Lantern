## 한 줄 정의
에이전트를 돌려 두고 자리를 비워도 맥은 일이 끝날 때까지 깨어 있고, 할 일은 화면 우측 상단에 걸어 둔 작은 창에 항상 떠 있는 macOS 앱.

## 화면 (기획 문서의 "메뉴바 드롭다운이 메인"은 폐기)
- **메인은 우측 상단에 떠 있는 작은 창**: 테두리 없는 `NSPanel` + SwiftUI. `level = .floating`, `.nonactivatingPanel`, `.canJoinAllSpaces`/`.fullScreenAuxiliary`, `hidesOnDeactivate = false`
- **평소 상태**: 기존 단색 디자인의 *배경만* 반투명(글자는 선명), 클릭은 뒤로 통과(`ignoresMouseEvents = true`). 투명도는 설정 슬라이더, 흐림(material/Liquid Glass)은 토글
- **활성 상태**: 메뉴바 아이콘 왼쪽 클릭 → 색이 차오르며 불투명, 조작 가능
  - 평소로 복귀: 아이콘 다시 클릭 / 창 밖 클릭(`NSEvent.addGlobalMonitorForEvents`) / 10초 무조작 (입력 중 제외)
  - 단축키(예: ⌥⌘K)로도 전환. "마우스 올리면 활성화"는 설정 옵션 (0.25초 머무름, 0.5초 유예)
- **메뉴바 아이콘**: `MenuBarExtra`가 아니라 `NSStatusItem` 직접 사용. 오른쪽 클릭 = 메뉴(2시간 깨어 있기, 창 숨기기, 설정, 종료). 아이콘 모양으로 상태 표시(꺼짐 / 깨어 있음 / 뚜껑 모드)
- 창 안: 깨어 있기 상태·남은 시간, 언제까지, 뚜껑 모드, "지금 닫으면 유지됨/잠듦", 에이전트 상태, 오늘 할 일. 접으면 한 줄("깨어 있는 중 · 1:42 · 할 일 3")
- M1 구현에서 정한 세부 동작
  - "언제까지" 세그먼트는 메뉴처럼 **고르면 바로 시작**. "시각"은 시각 입력 줄을 열고 "시작"을 눌러야 시작
  - 접기는 평소 상태의 모습만 정함. 활성 창의 ⌃(접어 두기) → 한 줄로 접히고 평소로, 접어 둔 동안 같은 자리는 ⌄(펼쳐 두기). 아이콘 클릭으로 활성이 되면 접어 뒀어도 전체 창. 접힘 여부와 마지막 탭은 UserDefaults에 저장
  - Esc도 평소 상태로 복귀(시각 입력 중 제외). 마우스가 창 위에 있으면 10초 무조작으로 치지 않음
  - 활성 상태에서만 창이 키 입력을 받고, 평소로 돌아가면 키 입력을 원래 앱에 돌려줌
  - "뚜껑 닫아도 유지" 스위치는 M2에서 "지금 뚜껑을 닫으면" 아래에 붙임(권한이 없으면 🔒 설정, 메뉴에도 같은 항목). "연장 ›"은 아직. 할 일 탭은 M4 전까지 자리만 있고, 그 전까지 기본 탭은 깨어 있기
  - 메뉴바 메뉴의 "지금 닫으면" 줄은 창으로 옮김. 메뉴에는 "시각…"(창을 열어 시각 입력)과 "창 숨기기/보이기"
  - Figma는 "랜턴 · 확정 디자인" 섹션 하나만 남기고 나머지 시안은 삭제(2026-10-24)

## 깨어 있기 구조 (확정)
- 세션 하나 + 옵션 두 개: **언제까지**(계속/1·2시간/직접/에이전트가 끝날 때까지), **뚜껑 닫아도 유지**(세션 안에서만)
- 세션이 끝나면 둘 다 꺼짐(뚜껑 모드를 먼저 끔)
- 안전장치 (2026-10-26)
  - 배터리 기준: 충전기 없이 기준 %에 **닿는 순간 한 번** 깨어 있기를 통째로 끔. 그 뒤 사용자가 다시 켜면 그 선택을 따름(충전기를 꽂거나 기준보다 올라가면 다시 동작). 단 기준 아래에서 뚜껑 모드는 못 켬
  - 발열: 뚜껑 모드 중 `thermalState`가 `.serious` 이상이면 **뚜껑 모드만** 끄고 깨어 있기는 유지. 뚜껑을 열어 둔 상태의 발열은 macOS 기본 보호(팬·속도 낮춤·비상 종료)로 충분하고, 깨어 있기를 꺼도 식지 않고 작업만 멈추기 때문. 위험은 "잠든 줄 알고 닫아 가방에 넣는" 경우뿐
  - 어느 쪽이든 뚜껑이 닫혀 있었으면(`AppleClamshellState`) 바로 재움(`pmset sleepnow`). 닫힌 뒤에 뚜껑 모드를 풀면 macOS는 스스로 잠들지 않음(2026-10-26 실기 확인: 시간이 끝나 꺼졌는데 3분 넘게 깨어 있었음). 세션이 끝날 때도 같음. 단 클램쉘 모드(전원+외장 모니터)처럼 뚜껑 모드 없이도 깨어 있을 상황이면 재우지 않음
  - 앱 시작 시 `SleepDisabled`가 1이면 끔, 앱 종료 시에도 끔. 동작할 때만 알림
- 감시 작업 (M2 4단계): 뚜껑 모드를 켤 때 `~/Library/LaunchAgents/com.songkyuseob.lantern.watchdog.plist`를 등록하고 끌 때 지움. `~/Library/Application Support/Lantern/랜턴 뚜껑 모드 감시` 스크립트(시스템 설정 "앱 백그라운드 활동"에 실행 파일 이름이 보이므로 `/bin/sh -c`로 하면 "sh"로 보여 이름 있는 파일로 바꿈, `AssociatedBundleIdentifiers`는 ad-hoc 서명에서 효과 없었음)가 5초마다 랜턴 PID가 같은 실행 파일로 살아 있는지 확인(`ps -p PID -o comm=`), 사라지면 `sudo -n pmset -a disablesleep 0` 후 스크립트·등록 파일을 스스로 지움(2026-10-26 Xcode 정지로 실기 확인). `RunAtLoad`라 맥이 강제로 꺼져도 다음 로그인 때 같은 일을 함. 앱 시작 시 남은 것도 정리
- 뚜껑 모드 켜짐 여부는 랜턴이 기억한 값이 아니라 `pmset -g`의 `SleepDisabled`로 판단
- 깨어 있기 = `IOPMAssertion`, 뚜껑 모드 = `pmset -a disablesleep 1` (sudoers에 정확한 명령 3개만, `visudo -c` 검사)
- 자세한 주의사항은 `docs/기획.md`의 "주의해야 할 것"

## 에이전트 감지 (M3, 방향 확정)
- hook은 모델이 아니라 **에이전트 프로그램**(Claude Code `~/.claude/settings.json`, Codex `~/.codex/hooks.json`)에 건다. 터미널·오르카·IDE 등 어디서 실행해도 같은 설정을 읽으므로 실행 도구별 지원은 필요 없다
- 시작 = `UserPromptSubmit`, 끝 = `Stop` (+ `StopFailure`, `SessionEnd`)
- 프로세스 감시만으로는 부족: Claude Code는 작업을 끝내고 입력 대기 중에도 프로세스가 살아 있음
- 참고 구현: 오르카가 같은 방식으로 hook을 설치해 둠 (`~/.orca/agent-hooks/`). 단 오르카 hook은 오르카 환경 변수가 있을 때만 동작하고, 랜턴 hook은 조건 없이 동작해야 함
- 지킬 것: 기존 hook(오르카 등)을 건드리지 않고 추가·제거, 여러 에이전트 동시 실행 시 전부 끝나야 세션 종료, 끝 신호 누락에 대비한 최대 시간 안전장치
- 대상은 내 맥에서 도는 CLI 에이전트만. 클라우드 에이전트는 맥을 깨워 둘 필요가 없음

## 코드 규칙
- UI와 무관한 로직(세션, 전원 판단, 안전장치, 할 일 저장소 프로토콜)은 `LanternKit`에. AppKit 의존은 앱 타깃에만
- SwiftData 모델은 나중에 CloudKit을 켤 수 있게: 모든 속성에 기본값 또는 옵셔널, `@Attribute(.unique)` 금지, 관계는 옵셔널
- 세션 상태·기록은 `Codable`
- 할 일 저장소는 프로토콜 뒤에

## 확인한 것
- 2026-10-25 실기 확인: macOS 26에서 `sudo pmset -a disablesleep 1` 상태로 충전기만 연결(외장 모니터 없음)하고 뚜껑을 닫아도 잠들지 않음(디스코드 음성 유지, `pmset -g log`에 잠자기 기록 없음). 확인 후 `0`으로 복구
- 2026-10-26 뚜껑 모드 권한 설치·제거 실기 확인: `/etc/sudoers.d/lantern`이 root:wheel `0440`으로 설치되고, 규칙 밖 명령(`sudo -n pmset -g`)은 "a password is required"로 거부됨
- 2026-10-26 배터리만(충전기·외장 모니터 없음) + 랜턴 뚜껑 모드 스위치로 뚜껑을 닫아도 1분 넘게 음악 유지, 잠자기 기록 없음 → **배터리일 때도 `disablesleep 1`이 동작**. 같은 조건에서 스위치를 켜지 않았을 때는 'Clamshell Sleep'으로 바로 잠듦
- 주의: `sudo -n -l <명령>`은 비밀번호가 필요한 관리자 규칙(`(ALL) ALL`)으로도 통과하므로 "비밀번호 없이 되는지" 판단에 쓸 수 없다. 설치 여부는 `sudo -n -l` 규칙 목록에서 NOPASSWD 명령을 찾아 판단한다(`SudoListing`). sudo는 긴 줄을 화면 폭에 맞춰 끊어 출력하므로 공백·줄바꿈을 합쳐서 읽는다
